Serial protocol

115200 8N1. Newline-terminated ASCII. Same verbs in the simulator and ESP32 firmware.

Host → device

PING
STATUS
SORT plastic_metal
SORT paper
SORT glass

RESET

Device → host

PONG firmware=1.0.0 mode=live
SENSORS ir=1 moist=0.12 metal=0
SORT_OK bin=paper t_ms=1180 disc=90 flap=18
SORT_ERR reason=jam
